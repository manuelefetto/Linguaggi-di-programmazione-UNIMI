# Esercizi linguaggi di programmazione

Repository contenente tutti gli esercizi svolti per il corso di linguaggi di programmazione dell'Università degli studi
di Milano durante l'anno 2025/2026 del professor Walter Cazzola.

La repository è suddivisa per laboratori. Per ogni laboratorio vi è una serie di file o cartelle rappresentanti gli esercizi.
Il testo dell'esercizio è consultabile o [Sito del corso](https://cazzola.di.unimi.it/lp.html) o nel commento iniziale del file degli esercizi.
